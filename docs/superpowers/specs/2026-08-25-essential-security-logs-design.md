# O'range Textile Essential Security Logs and Analytics Choice Design

**Date:** 2026-08-25

**Status:** Ready for written-spec review

**Scope:** Local policy, consent-interface, and test changes only. No production deployment, Vercel Firewall publication, Bot Protection activation, challenge, blocking, or application-owned IP database.

## 1. Outcome

Explain accurately that O'range Textile and its hosting provider continue to process limited, necessary security and operational information when a visitor declines Analytics cookies or has not made an Analytics choice. Keep this processing separate from Google Analytics consent and do not expand advertising permissions.

The design uses Vercel's hosting and security layer for IP-based security analysis. The website application will not create a separate raw-IP collection endpoint or IP database.

## 2. Confirmed Decisions

- Use the platform-native approach: Vercel Firewall and Bot Protection are the intended security-analysis layer.
- Full IP addresses remain within Vercel's hosting and security layer.
- O'range Textile will not create a separate application IP database.
- Security logs available to O'range Textile will be retained for no more than 30 days, or for a shorter period when platform availability requires it.
- Essential security logging continues when a visitor declines Analytics cookies or has not made a choice.
- Security logs are used only to deliver and protect the website, identify automated or abusive traffic, investigate security incidents, and diagnose availability or technical problems.
- Security logs are not used for advertising or cross-site profiling.
- O'range Textile does not add IP addresses to GA4 event parameters. Google necessarily receives the source IP when the browser connects to its collection endpoint, uses it at collection time to derive location, and states that it discards the IP before Analytics data is logged.
- The consent banner will disclose that essential security logs operate regardless of the Analytics choice.
- The consent banner's legal link will point to the Privacy Policy rather than the Terms of Service.
- Vercel Bot Protection is intended to begin in Log mode only. Enabling Log mode in production requires separate user approval.
- Challenge, deny, block, rate-limit, and other production enforcement actions are outside this scope and require separate approval.

## 3. Data and Processing Boundaries

### Essential security and operational information

The Privacy Policy will disclose that Vercel may process:

- IP address;
- request date and time;
- User-Agent;
- requested path;
- response status;
- referrer where available; and
- related security signals generated by the hosting or security layer.

Request timestamps may be used with request sequences to investigate a visit, but the policy will not claim that the platform always produces an exact GA4-style session duration.

### Explicit exclusions

This work will not:

- create an application API route for raw IP logging;
- create or configure a database for IP storage;
- create a new browser identifier, fingerprint, Cookie, or localStorage record;
- send raw or hashed IP addresses to GA4 or GTM;
- combine security logs with inquiry form content for profiling;
- use security logs for advertising, remarketing, personalization, or cross-site tracking;
- change the two-month GA4 event-level retention setting; or
- change the inquiry-data retention wording.

## 4. Consent and Analytics Data Flow

The runtime sequence remains:

1. A request reaches Vercel's hosting and security layer.
2. Vercel processes necessary request and security information independently of the website's Analytics choice.
3. The page sets Google Consent Mode defaults before GTM starts.
4. `analytics_storage`, `ad_storage`, `ad_user_data`, and `ad_personalization` default to `denied`.
5. GTM starts asynchronously under the denied state and may send restricted cookieless measurement.
6. Accept changes only `analytics_storage` to `granted`.
7. Decline or no choice leaves Analytics storage and all advertising permissions denied.

Essential security logs are not controlled by the Analytics Accept and Decline buttons. Decline means that Analytics cookies remain disabled; it does not disable necessary hosting, security, abuse-prevention, or diagnostic processing.

## 5. Privacy Policy Design

Add a section titled `Essential security and server logs` with the following reviewed copy:

> When you visit the website, our hosting and security provider may process your IP address, request date and time, User-Agent, requested path, response status, referrer where available, and related security signals. This processing continues if you decline Analytics cookies or have not made a choice. We use this information only to deliver and protect the website, identify automated or abusive traffic, investigate security incidents, and diagnose availability or technical problems. We do not use these logs for advertising or cross-site profiling. We do not add IP addresses to Google Analytics event data. When your browser connects to Google Analytics, Google may use the source IP at collection time to derive location information and states that it discards the IP before Analytics data is logged. Full IP addresses used for our own security analysis remain within Vercel's hosting and security layer; O'range Textile does not create a separate application IP database. Security logs available to us are retained for no more than 30 days, or for a shorter period when required by platform availability.

Also update:

- `Providers and international processing` to identify Vercel as the hosting and security provider and describe potential processing outside the visitor's location under Vercel's terms and privacy arrangements;
- `Retention` to distinguish the 30-day maximum for security logs available to O'range Textile from the two-month GA4 event-level retention period;
- `Your choices and requests` to explain that Decline controls Analytics cookies but does not stop necessary security logging; and
- the Privacy Policy effective date to `August 25, 2026`.

The policy remains an operational draft and not a substitute for jurisdiction-specific legal advice.

## 6. Consent Banner Design

Preserve the existing full-width layout, accessible region, focus behavior, Accept and Decline actions, and visual hierarchy.

Use this body copy:

> We use basic cookieless measurement by default. Accepting enables analytics cookies for more complete traffic and conversion reporting. Essential security logs operate regardless of your Analytics choice. You can change your choice at any time through Privacy settings in the footer. Read our Privacy Policy.

`Privacy Policy` links to `/privacy` with prefetch disabled. The button labels and accessible names remain:

- `Decline` / `Decline analytics cookies`
- `Accept` / `Accept analytics cookies`

The new disclosure must not imply that essential security logs are GA4 data or that rejecting Analytics is ineffective. It distinguishes necessary platform security processing from optional Analytics-cookie storage.

## 7. Failure and Safety Behavior

- If Vercel log access is unavailable, delayed, limited by plan, or denied, the website continues to operate.
- The application will not fall back to storing raw IP addresses.
- Consent storage failures continue to fail closed for Analytics: Analytics cookies remain off and the existing warning remains visible.
- Security-log availability does not alter Consent Mode commands.
- Bot classifications are probabilistic. Log mode is used before any later enforcement decision to reduce false positives.
- Production Bot Protection, Firewall rules, challenges, or blocks are not activated by this local work.

## 10. Production Boundary

Local code and verification do not authorize deployment or external configuration changes.

After local verification, the user must separately approve:

1. deploying the website changes; and
2. enabling Vercel Bot Protection in Log mode.

No production Challenge, Block, Deny, or rate-limiting rule is implied by approval of Log mode.
